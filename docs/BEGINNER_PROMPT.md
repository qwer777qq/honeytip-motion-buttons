# 초보자용: 버튼을 보고 한 번에 복사하기

1. [움직이는 버튼 8종 미리보기](https://qwer777qq.github.io/honeytip-motion-buttons/)에서 마음에 드는 번호를 고릅니다. 마우스를 올리거나 키보드로 초점을 옮기면 움직임을 볼 수 있습니다.
2. 아래 프롬프트 전체를 복사해 Codex 또는 Claude Code에 붙여넣습니다. 대괄호 부분은 아는 것만 채워도 됩니다.
3. 1~4번은 현재 워드프레스에 등록되어 있습니다. 5~8번은 [추가 플러그인](../wordpress/honeytip-motion-buttons.zip)을 적용해야 합니다.

```text
워드프레스 글에 움직이는 버튼을 넣어 주세요.

내가 고른 디자인 번호: [1~8 중 숫자]
버튼을 넣을 글 주소: [글 URL]
버튼 문구: [예: 공식 사이트 바로가기]
버튼이 열 주소: [https://...]
넣을 위치: [예: 첫 번째 소제목 아래]

먼저 디자인 8종을 https://qwer777qq.github.io/honeytip-motion-buttons/ 에서 확인하고, 코드와 설치법은 https://github.com/qwer777qq/honeytip-motion-buttons 를 참고해 주세요.
1 네이비 입체 점프 / 2 청록 빛 스윕 / 3 보라 화살표 슬라이드 / 4 아이스 블루 테두리 채움은 현재 사이트에 등록된 디자인입니다.
5 코랄 입체 점프 / 6 앰버 빛 스윕 / 7 민트 화살표 슬라이드 / 8 로즈 테두리 채움은 GitHub 플러그인을 적용해야 하는 추가 디자인입니다.

글은 비주얼 블록 편집기로 유지하고 /버튼 패턴을 사용해 주세요. 가운데 정렬, 모바일 반응형, 키보드 포커스, 움직임 줄이기 설정을 확인해 주세요. 기존 글과 버튼, 링크는 보존해 주세요. 빈 입력값이 있으면 적용 전에 필요한 값만 물어봐 주세요. 적용 후 실제 글에서 버튼 모양과 링크를 확인하고 결과를 알려 주세요. 로그인이나 인증이 필요하면 내가 직접 처리하도록 안내하고 비밀번호를 대화나 파일에 기록하지 마세요.
```
