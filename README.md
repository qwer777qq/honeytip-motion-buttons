# 꿀팁매거진 움직이는 버튼 8종

꿀팁매거진에서 쓰는 가운데 정렬 CTA 4종을 출발점으로, 움직임 4가지와 색상 8가지를 비교하는 독립 데모입니다. 외부 애니메이션 라이브러리의 코드를 복사하지 않았습니다.

**[움직이는 버튼 직접 보기](https://qwer777qq.github.io/honeytip-motion-buttons/)** · [꿀팁매거진](https://honeytipmagazine.com/)

| 번호 | 버튼 | 상태 | 움직임 |
| --- | --- | --- | --- |
| 1 | 네이비 입체 점프 | 워드프레스 등록 | 크게 떠오르고 화살표가 움직임 |
| 2 | 청록 빛 스윕 | 워드프레스 등록 | 빛이 가로지름 |

| 4 | 아이스 테두리 채움 | 워드프레스 등록 | 윤곽선 안쪽이 채워짐 |
| 5 | 코랄 입체 점프 | 이 저장소의 추가 디자인 | 따뜻한 색상으로 상승 |
| 6 | 앰버 빛 스윕 | 이 저장소의 추가 디자인 | 황금빛 버튼 위로 빛이 이동 |
| 7 | 민트 화살표 슬라이드 | 이 저장소의 추가 디자인 | 민트색 화살표가 이동 |
| 8 | 로즈 테두리 채움 | 이 저장소의 추가 디자인 | 로즈색 채움 |

## 워드프레스에서 사용하기

기존 4종은 글의 빈 문단에서 `/버튼`을 입력한 뒤 `버튼 · …` 패턴을 선택합니다. 문구와 이동할 주소를 글마다 바꿀 수 있습니다.

추가 4종을 등록하려면 [`wordpress/honeytip-motion-buttons.zip`](wordpress/honeytip-motion-buttons.zip)을 다운로드해 **플러그인 → 새 플러그인 추가 → 플러그인 업로드**에서 설치하고 활성화합니다. 활성화 후 `/버튼` 검색에서 `버튼 · 코랄 점프`, `버튼 · 앰버 빛 스윕`, `버튼 · 민트 화살표`, `버튼 · 로즈 채움`을 고릅니다. 이 플러그인은 기존 4종을 덮어쓰지 않습니다. 실제 사이트에 설치하기 전에는 테스트 초안에서 문구·링크·모바일 표시를 확인하세요.

`index.html`, `styles.css`, `script.js`는 GitHub Pages 데모 전용입니다. 데모의 **HTML 복사**는 모양을 참고하는 개발자용 코드이며, 일반 글쓴이는 Gutenberg 패턴을 쓰는 편이 쉽습니다.

## 파일

- `index.html`, `styles.css`, `script.js`: 버튼 8종 실시간 데모
- `wordpress/honeytip-motion-buttons/`: 새 색상 4종의 Gutenberg 패턴 플러그인
- `assets/`: 노션에 붙일 움직이는 GIF 미리보기와 표지
- `docs/BENCHMARK.md`: 참고 사례와 독립 구현 기준
- `docs/DEVELOPMENT_PROMPT.md`: Codex·Claude Code용 실행 프롬프트

## 품질 기준

- 폭 최대 480px, 부모보다 넓어지지 않음, 기본 가운데 정렬
- 마우스 호버와 키보드 포커스에 반응하며 모바일은 눌림 피드백 제공
- `prefers-reduced-motion: reduce`에서 불필요한 이동 제거
- 글쓴이가 문구와 URL을 블록에서 직접 바꿀 수 있음

비밀번호나 인증 코드는 이 저장소에 넣지 않습니다.
